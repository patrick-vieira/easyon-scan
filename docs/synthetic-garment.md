# Synthetic garment fixture

Run `easyon-scan synthetic-garment --out /tmp/fixture --sizes P,M,G`. The explicit table in `easyon_scan/synthetic_garment.py` defines all dimensions in millimetres. Each size has six rectangular panels: front, back, two sides and two shoulders. The DXF uses ASTM-style numeric layers 1 (cut), 14 (sew), 4 (notch) and 7 (grain), with Piece Name, Size Name and Quantity labels. These shapes are deliberately simple contract fixtures, not production patterns.

The command writes DXF, adapter-derived assembly v0, assembly v1, a separate segment-pair truth file, and a `propose_assembly` evaluation per size. The v1 contains eight synthetic plain seam pairs: each side and shoulder bridge joins both front and back. Its review stays pending; the fixture decisions only record the known synthetic construction and do not represent human approval. The evaluation runs the actual proposer and lists each truth pair's rank, orientation, construction and failure reason. The proposer currently leaves construction unresolved, so zero fully correct pairs can be a useful result rather than a generator failure. Evaluation uses a declared 1 mm endpoint tolerance and measures this synthetic fixture only. `manifest.json` records SHA-256 of every other artifact. DXF export and CAD compatibility remain experimental. See `docs/precision-notes.md` and `docs/benchmark.md` for measurement limits.
